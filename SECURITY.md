# Security policy

## Development status

MrNinjam `0.2.1` is a development-stage source-code preview. The project
has not published an official binary release and does not currently designate
any released version as supported for security updates. Reports against the
current `main` source are still welcome and will be assessed on their merits.

## Reporting a vulnerability

Do not include vulnerability details, credentials, private server information,
or personal data in a public issue.

If GitHub displays **Report a vulnerability** for this repository, use that
private reporting form. If it is unavailable, open a minimal public issue
asking the maintainer to establish a private contact channel, without including
the sensitive details.

Ordinary bugs that do not have a security impact may be reported through the
public issue tracker.
