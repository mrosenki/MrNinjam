## Incorporated or modified third-party code

- NINJAM `njclient` is GPL-2.0-or-later. The project patch changes
  `njclient.cpp` and `njclient.h` and records the modification and date.
- WDL/JNetLib files used by the runtime carry their own permissive source
  notices.
- The Visage patch changes styling constants in
  `visage_widgets/text_editor.cpp`; the upstream Vital Audio notice remains.
- CLAP, clap-wrapper, bundled fmt, the PreSonus extension, and the VST3 SDK
  retain their upstream terms.
- The Visage graphics link graph includes FreeType, bgfx, bx, bimg, and bimg's
  compiled third-party codec/image sources. The reviewed inventory is in
  `THIRD_PARTY_NOTICES.md`.

Patches are applied only to disposable build-owned copies. Locked dependency
checkouts remain pristine.

## Separately obtained build dependencies

Third-party source is not vendored into the approved snapshot.
`dependencies.lock` declares the direct source repositories and immutable
commits. `scripts/fetch_dependencies.sh` and its PowerShell counterpart
create ignored checkouts under `deps/` and `external/`.

The VST3 SDK, bgfx.cmake, and FreeType parents contain nested sources whose
revisions are verified by the fetch scripts and documented in
`docs/DEPENDENCIES.md`. System or package-manager Ogg/Vorbis resolution is
still provisional; direct Xiph pins are documented as the next technical task
but have not been added to the lockfile or build.

The project mixer additionally embeds
`visage/examples/fonts/Lato-Regular.ttf`; it is byte-for-byte identical to the
Lato file listed above. The unused Droid copy in `examples/fonts/` is likewise
identical to the core Droid asset, but Visage example targets are disabled.
Other fonts found inside ignored bgfx and VSTGUI example trees are not built
or packaged by NinjamPlugin.

Visage also embeds shader sources and `check_circle.svg`, `menu.svg`, and
`x_circle.svg`. No separate notices were found next to those files; the
`menu.svg` file says it was generated by IcoMoon. Their exact upstream
origin and any notice beyond the Visage repository licence remain unresolved
before public release. Visage's prebuilt host `shaderc` executables are build
tools rather than packaged plug-in files, but their provenance and integrity
also remain to be documented.

## Excluded provenance

The historical Git graph, private tutorial, phase reports, recordings, logs,
crash reports, connection settings, packaged plug-ins, build caches, generated
renders, dependency worktrees, and operating-system metadata are excluded from
the proposed initial snapshot. The historical project remains an evidence
archive and is not a source or build dependency.
